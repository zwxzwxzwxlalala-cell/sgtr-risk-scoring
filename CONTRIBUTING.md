# Contributing

Use synthetic data for examples and tests. Include a minimal reproducible case and the Python/NumPy versions when reporting a bug. Do not attach real customer data, identifiers, predictions, trained models, credentials or restricted third-party documents.

Changes to the demonstration should preserve the documented objective or explicitly identify a different method. Published research results are a fixed evidence snapshot and are not regenerated by the demo. New experiments belong in separately named results, not in the frozen tables.

Contributions to project code are accepted under the repository's MIT license. Discuss substantive changes to research claims before editing the frozen evidence tables.
